# Agent roles — protocol, not dispatcher

Intended workflow: Host supervises; a distinct Architect proposes a brief/team plan; the owner approves the brief and reviewed plan; specialists work only within the approved scope. Each author must have a separate reviewer where the host permits it.

If independent host-native agents cannot be instantiated, report `ASSIGNMENT_ONLY` and mark independence `BLOCKED`. Never simulate separate identities as independent agents or claim automatic launch from this package.
