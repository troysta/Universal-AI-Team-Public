# Offline Notes — synthetic trial

Open `notes.html` directly in a browser (including from a phone's extracted folder). No server, account, internet connection, or installation is required.

1. Type a short note into the text box.
2. Tap **Display note** to show it below. Empty or whitespace-only notes are rejected with a message.
3. Tap **Clear note** to remove both the draft and displayed note.

This is deliberately temporary: refreshing or closing the page loses the note. The page has no external files, dependencies, or network requests. Phone-browser and airplane-mode checks must be performed on the actual device before claiming those outcomes verified.
